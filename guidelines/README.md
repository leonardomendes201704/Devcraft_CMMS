## How To Use

- Link related docs and ADRs.
- Keep commands copy-paste ready.

## Language Policy

- Guidelines, lessons-learned e known-issues: PT-BR.
- Conteudo de tasks no Kanban (title, description, module), snippets de CHANGELOG.md e board.md: **sempre PT-BR** (ver `workflows/task-lifecycle-directive.md` secao "Language Policy").
- Comentarios de codigo: PT-BR quando contextual; identificadores (classes, rotas, variaveis) permanecem em ingles.
- Mensagens de commit: ingles curto (convencao conventional commits), mas corpo do commit pode citar a task em PT-BR.
